# 📖 Glossaire

Terminologie utilisée dans ce projet.

## A

**Active Directory (AD)**  
Service d'annuaire Microsoft pour la gestion des utilisateurs, groupes et ressources dans un domaine Windows.

**Agent**  
Logiciel installé sur un endpoint qui collecte et envoie des données vers un serveur central (ex: Wazuh Agent, Elastic Agent).

## B

**Blue Team**  
Équipe de défense chargée de détecter, analyser et répondre aux attaques.

## D

**Domain Controller (DC)**  
Serveur Windows qui gère l'authentification et les politiques de sécurité d'un domaine AD.

## E

**Event ID**  
Identifiant numérique d'un type d'événement Windows (ex: 4624 = connexion réussie).

**EVTX**  
Format de fichier des journaux d'événements Windows.

## F

**FIM (File Integrity Monitoring)**  
Surveillance des modifications de fichiers critiques.

## G

**GOAD (Game of Active Directory)**  
Lab AD vulnérable pour l'entraînement à la sécurité offensive/défensive.

**GPO (Group Policy Object)**  
Mécanisme Windows pour appliquer des configurations de sécurité.

## H

**HIDS (Host-based Intrusion Detection System)**  
Système de détection d'intrusion installé sur les endpoints.

## I

**IDS (Intrusion Detection System)**  
Système qui détecte les activités malveillantes dans le réseau ou sur un hôte.

**IPS (Intrusion Prevention System)**  
IDS avec capacité de bloquer les attaques détectées.

## M

**MITRE ATT&CK**  
Base de connaissances des tactiques et techniques d'attaque.

## N

**NIDS (Network-based IDS)**  
IDS qui analyse le trafic réseau (ex: Suricata, Snort).

## O

**OpenWEC**  
Collecteur open-source de Windows Event Forwarding.

## P

**PCAP**  
Format de capture de paquets réseau.

## R

**Red Team**  
Équipe offensive qui simule des attaques pour tester les défenses.

## S

**SIEM (Security Information and Event Management)**  
Plateforme centralisant les logs pour la détection et l'investigation.

**Sigma**  
Format générique de règles de détection, convertible vers différents SIEMs.

**Suricata**  
IDS/IPS open-source haute performance.

**Sysmon (System Monitor)**  
Outil Microsoft qui enrichit les logs Windows avec des événements détaillés.

## W

**Wazuh**  
Plateforme SIEM/XDR open-source avec détection d'intrusion.

**WEF/WEC (Windows Event Forwarding/Collector)**  
Mécanisme natif Windows pour centraliser les logs.

**WinRM**  
Protocole de gestion à distance Windows (ports 5985/5986).
